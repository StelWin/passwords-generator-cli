# 🔐 Password Generator

A simple, fast command-line tool for generating secure, human-readable passwords.

### 🚀 Features

- Generates strong, random passwords instantly
- Easy to use from the terminal
- Pure Python — no external dependencies (uses only the standard library: secrets, string)
- Perfect for developers, sysadmins, and anyone who values security

---

### 💻 Usage

**Example:**

```
$ newpass
uvufag-Jau3uv-3kanfF-sju3gs
```

**Run directly:**

```
python newpass.py
```

---

### 🛠️ Installation

Install as a command-line tool for global use:

```
pip install --editable .
```

Then simply run:

```
newpass
```

---

### 🧠 About

This project was built to make generating secure passwords effortless — without depending on external libraries or complex setup.
